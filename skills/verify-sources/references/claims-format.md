# Формат claims.json

Список утверждений отчёта. Одно утверждение — один объект. Файл лежит рядом с отчётом.

```json
[
  {
    "id": "1",
    "claim": "Гайд для полуструктурированного интервью можно использовать гибко: менять порядок вопросов и пропускать их.",
    "source": "https://www.nngroup.com/articles/interview-guide/",
    "quote": "an interview guide can be used flexibly: interviewers can ask questions in any order they see fit, omit questions",
    "location": "Introduction"
  },
  {
    "id": "2",
    "claim": "Боль снизилась на 1,2 балла по шкале NRS.",
    "doi": "10.1016/S2665-9913(25)00151-1",
    "quote": "between-group difference -1·2",
    "location": "Abstract, Findings"
  }
]
```

Поля:
- `id` — номер утверждения, его же ставим в отчёте рядом с текстом: `[1]`.
- `claim` — утверждение, как оно написано в отчёте. Числа из него программа ищет в цитате и в источнике.
- `source` — ссылка на страницу. Для научной статьи вместо неё `doi`.
- `quote` — дословный кусок источника на его языке, без пересказа и перевода. Чем точнее, тем надёжнее проверка.
- `location` — где в источнике: раздел, страница, таблица.

Утверждение без источника тоже записывается, с пустыми `source` и `quote`. Программа вынесет его в отдельный список.

Необязательные поля:
- `data` — число из таблицы, xlsx или выгрузки: файл, лист, строка, столбец, значение. `quote` пустой. Программа такое утверждение не проверяет и выносит в список «число из файла» для сверки новой сессией.
- `дата`, `период` — дата публикации и период данных.
- `against: true` — источник против гипотезы или вывода.
- `unconfirmed: true` — источник недоступен, утверждение помечено «не подтверждено».

Навык `desk-research` собирает `claims.json` из файлов фактов скриптом `scripts/raw_to_claims.py`.
