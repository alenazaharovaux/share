# Установка навыка verify-sources — инструкция для агента

Ты агент: Codex или Claude Code. Навык `verify-sources` проверяет программой цитаты и числа в отчёте по самим источникам.

Установка общая с навыком `desk-research`. Открой в том же репозитории файл `skills/desk-research/INSTALL-AGENT.md` и выполни его по шагам.

Одно отличие. До шага 2 спроси пользователя: «Поставить вместе с verify-sources навык desk-research для кабинетных исследований?»
- «Да» — ставь оба навыка, как написано в инструкции.
- «Нет» — ставь только папку `verify-sources`. Программы desk-research на шаге 4 не запускай. В шаге 6 вместо вопросов первого запуска скажи, что у verify-sources их нет, и дай примеры: «проверь источники в report.md», «сверь цитаты и цифры в этом обзоре».
