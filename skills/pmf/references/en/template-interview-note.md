# Template — Interview Note

**Used in:** Stage 6 (Field — outside the skill) and Stage 7 (Synthesis — for reading)
**Save as:** `interviews/notes/[respondent-id]-[YYYY-MM-DD].md` in the project folder
**Companion guides:** `references/<lang>/stage-5-interview-prep.md`, `references/<lang>/stage-7-interview-synthesis.md`

**Purpose:** one note for one interview. The structure is the same for all notes so that Stage 7 (synthesis) can read each one in isolation and extract patterns.

## Filling guidance

**Fill immediately after the interview**, within 24 hours. Memory distorts after a day.

**Verbatim quotes — verbatim**, not paraphrase. If you do not remember word for word — mark "[paraphrase]".

**Do not interpret while writing the note** — record facts and quotes. Interpretation comes in Stage 7.

**One file per one interview.** Do not merge. This is critical for read isolation in synthesis.

**File name:** `[respondent-id]-[YYYY-MM-DD].md` where respondent-id = initials or an anonymous ID, date of interview.
- Example: `MK-2026-04-15.md`
- Example: `R03-2026-04-16.md`
