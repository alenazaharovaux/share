# Как записать термин в terminy.md

Файл `~/poyasnitelnaya-brigada/terminy.md` — источник страницы глоссария. Страницу собирает `scripts/build_glossary.py`, руками HTML не правь.

Новый термин ставь сверху, сразу под строкой-комментарием `<!-- Новые термины добавляй сверху… -->`.

## Формат

```markdown
## API
- id: api
- дата: 2026-11-13
- сфера: Вайбкодинг
- стиль: Игра престолов
- источник: https://developer.mozilla.org/ru/docs/Glossary/API

### История
В Королевской Гавани к королю напрямую не ходят. Хочешь зерна из королевских амбаров — пишешь прошение по установленной форме и отдаёшь его Деснице. Десница принимает только прошения, составленные как положено: от кого, что просишь, сколько. Прошение не по форме возвращают нераспечатанным. По правильному прошению Десница сам идёт в амбары и возвращается с зерном, а если зерна дать нельзя, то с письменным отказом. Просящему не нужно знать, где амбары и кто их сторожит. API — это и есть Десница вместе с правилами прошений.

### Просто
API — это заранее оговорённый способ, которым одна программа просит другую сделать что-то или отдать данные.

### Пример
Сервис расшифровки отдаёт вашему агенту текст интервью через API: агент отправляет запрос с аудиофайлом и получает обратно текст.

### Вопросы
#### Чем API отличается от сайта?
Сайт сделан для человека: там кнопки и картинки. API сделан для программы: там только запросы и ответы в строгом формате.
```

## Поля

| Поле | Что писать |
|---|---|
| `## Название` | Термин так, как его пишут в источнике. Если в речи его зовут по-другому, добавь в скобках: `Hermes Agent (гермес-агент)`. |
| `id` | Латиница, дефисы. По нему комментарий на странице привязывается к термину. Не меняй у существующего термина. |
| `дата` | Дата добавления, `ГГГГ-ММ-ДД`. Страница ставит свежие сверху по этой дате. |
| `сфера` | Одна сфера из уже существующих в файле. Новую заводи, только если ни одна не подходит. Примеры: Вайбкодинг, ИИ-агенты, Исследования, Физика. |
| `стиль` | Стиль, в котором написана история. Берётся из `nastrojki.md` на момент записи. |
| `источник` | Ссылки через пробел. Для инструмента — официальный сайт или репозиторий. Источника нет — `источник: не нашла, проверьте сами`. |
| `### История` | 4–8 предложений в стиле. Правила — `references/stili.md`. |
| `### Просто` | Одно-два предложения обычным языком без новых терминов. |
| `### Пример` | Где человек встретит это в жизни или в работе. Без имён реальных людей из транскриптов. |
| `### Вопросы` | Появляется после комментариев. Каждый вопрос — `#### Вопрос`, ниже ответ. |

В тексте работают `**жирный**`, `*курсив*`, ссылки `[текст](https://…)` и списки через `- `.
