# Установка навыка «Пояснительная бригада» — инструкция для агента

Ты агент: Codex или Claude Code. В этой папке лежит навык `poyasnitelnaya-brigada`: объяснение терминов в стиле, который выбрал пользователь, и личный глоссарий в виде HTML-страницы.

Пользователь может быть новичком. Объясняй каждый шаг простыми словами, команды в терминале запускай сам. Чужие файлы не удаляй без согласия пользователя.

## 0. Если у тебя ссылка на GitHub

Пользователь дал ссылку вместо папки — скачай навык во временную папку:

```
git clone --depth 1 https://github.com/alenazaharovaux/share
```

Нужная папка — `share/skills/poyasnitelnaya-brigada`. Git нет — скачай архив https://github.com/alenazaharovaux/share/archive/refs/heads/main.zip и распакуй. После установки временную папку удали.

## 1. Проверь Python

Навык собирает страницу глоссария программой на Python 3. Выполни по очереди, пока одна из команд не покажет версию 3.x:

```
python --version
py --version
python3 --version
```

Запомни команду, которая сработала, и дальше используй её.

Python нет — скажи пользователю и предложи поставить:
- Windows: `winget install -e --id Python.Python.3.12`. Если `winget` нет, дай ссылку https://www.python.org/downloads/ и попроси при установке отметить галочку «Add python.exe to PATH».
- Mac: `brew install python`, если стоит Homebrew. Если нет, дай ссылку https://www.python.org/downloads/.

Ставь только после «да» пользователя. После установки закрой и снова открой терминал и проверь версию ещё раз.

## 2. Скопируй навык

Навык ставится в личную папку навыков, тогда он работает в любом проекте:
- Codex: папку `poyasnitelnaya-brigada` целиком в `~/.agents/skills/`.
- Claude Code: папку `poyasnitelnaya-brigada` целиком в `~/.claude/skills/`.

`~` — домашняя папка пользователя, например `C:\Users\<имя>` на Windows. Папки `skills` нет — создай её.

Копируй вместе с `references/` и `scripts/`. Если папка `poyasnitelnaya-brigada` там уже есть, покажи пользователю разницу и спроси, заменить ли.

## 3. Проверь программы

Выполни командой Python из шага 1:

```
<python> <папка навыков>/poyasnitelnaya-brigada/scripts/read_comments.py
<python> <папка навыков>/poyasnitelnaya-brigada/scripts/build_glossary.py
```

Первая программа без аргументов печатает подсказку по запуску. Вторая создаёт в домашней папке пользователя папку `poyasnitelnaya-brigada` с пустыми файлами `nastrojki.md` и `terminy.md` и кладёт пустую страницу глоссария в «Загрузки».

## 4. Проверь установку

Скажи пользователю открыть новый чат и набрать `$` в Codex или `/` в Claude Code. В списке должен появиться `poyasnitelnaya-brigada`. Если его нет, перезапусти приложение и проверь путь из шага 2.

## 5. Расскажи пользователю

Коротко напиши, куда лёг навык и где будут его данные и страница глоссария. Дай три примера запуска:
- «пояснительная бригада» — первый запуск, выбор стиля;
- «бригада, что такое RAG»;
- «бригада, найди все термины в <файл транскрипта>».
