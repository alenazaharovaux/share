# Установка навыков desk-research и verify-sources — инструкция для агента

Ты агент: Codex или Claude Code. Ставишь два навыка сразу:
- `desk-research` ведёт кабинетное исследование на открытых данных;
- `verify-sources` проверяет цитаты и числа программой.

desk-research работает только вместе с verify-sources: на шаге проверки он запускает программу из папки verify-sources. Поэтому ставь оба навыка в одну папку навыков, даже если пользователь назвал только один.

Пользователь может быть новичком. Объясняй каждый шаг простыми словами, команды в терминале запускай сам. Чужие файлы не удаляй без согласия пользователя.

## 0. Скачай навыки

Скачай репозиторий во временную папку:

```
git clone --depth 1 https://github.com/alenazaharovaux/share
```

Нужны две папки: `share/skills/desk-research` и `share/skills/verify-sources`. Git нет — скачай архив https://github.com/alenazaharovaux/share/archive/refs/heads/main.zip и распакуй. После установки временную папку удали.

## 1. Проверь Python

Программы навыков написаны на Python 3.8 или новее, сторонние библиотеки не нужны. Выполни по очереди, пока одна из команд не покажет версию 3.x:

```
python --version
py --version
python3 --version
```

Запомни команду, которая сработала, и дальше используй её.

Python нет — скажи пользователю и предложи поставить:
- Windows: `winget install -e --id Python.Python.3.12`. Если `winget` нет, дай ссылку https://www.python.org/downloads/ и попроси при установке отметить галочку «Add python.exe to PATH».
- Mac: `brew install python`, если стоит Homebrew. Если нет, дай ссылку https://www.python.org/downloads/.

Ставь только после «да» пользователя. После установки закрой и снова открой терминал и проверь версию ещё раз.

## 2. Скопируй оба навыка

Навыки ставятся в личную папку навыков, тогда они работают в любом проекте:
- Codex: папки `desk-research` и `verify-sources` целиком в `~/.agents/skills/`.
- Claude Code: папки `desk-research` и `verify-sources` целиком в `~/.claude/skills/`.

`~` — домашняя папка пользователя, например `C:\Users\<имя>` на Windows. Папки `skills` нет — создай её.

Копируй вместе с `references/` и `scripts/`. Если папка с таким именем там уже есть, покажи пользователю разницу и спроси, заменить ли.

## 3. Включи интернет для команд (только Codex)

Программа verify-sources открывает источники через интернет. В Codex интернет для команд по умолчанию выключен. Допиши в `~/.codex/config.toml`, если такой строки там ещё нет:

```toml
[sandbox_workspace_write]
network_access = true
```

Перед правкой покажи пользователю, что допишешь, и жди «да». В Claude Code этот шаг не нужен.

## 4. Проверь программы

Выполни командой Python из шага 1:

```
<python> <папка навыков>/desk-research/scripts/raw_to_claims.py
<python> <папка навыков>/desk-research/scripts/check_counts.py
<python> <папка навыков>/verify-sources/scripts/verify_sources.py
```

Каждая программа без аргументов печатает подсказку по запуску. Ошибка вместо подсказки — покажи её пользователю.

## 5. Проверь установку

Скажи пользователю открыть новый чат и набрать `$` в Codex или `/` в Claude Code. В списке должны появиться `desk-research` и `verify-sources`. Если их нет, перезапусти приложение и проверь путь из шага 2.

## 6. Расскажи пользователю

Коротко напиши, куда легли навыки. Скажи, что при первом запуске desk-research задаст четыре вопроса: где лежат проекты, где искать прошлые дески, есть ли карточка проекта, какие поисковые сервисы подключены. Любой вопрос можно пропустить. Дай три примера запуска:
- «кабинетка: что известно про влияние удалёнки на текучесть»;
- «быстрая справка: размер рынка онлайн-школ языков в Германии за 2024 год»;
- «проверь источники в report.md».
